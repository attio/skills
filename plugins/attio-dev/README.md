# Attio for developers

The Attio for developers plugin helps coding agents build on [Attio](https://attio.com). Its skills cover building and reviewing Attio apps with the [App SDK](https://docs.attio.com/sdk/overview), the REST API and MCP.

The plugin only adds skills. It doesn't connect to your Attio workspace or to any other service.

## Skills

The plugin's skills are in [`skills/`](skills).
