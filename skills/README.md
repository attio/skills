# Skills

Attio's agent skills. Each one follows the
[Agent Skills specification](https://agentskills.io/specification): a folder named after the
skill, a `SKILL.md` with `name` and `description` frontmatter, and optional `references/` loaded on
demand.

Skills are grouped into one folder per plugin, so each audience installs only the skills it needs.

## `attio-developers`

For building on Attio.

| Skill | Description |
| --- | --- |
| [`attio-apps`](attio-developers/attio-apps/SKILL.md) | Build, modify, debug, review and ship Attio App SDK apps |
